# ADRs

Architecture Decision Records (ADRs) capture major technical choices and their tradeoffs.

Current records:

- [0001: Monorepo package boundaries](./0001-monorepo-package-boundaries.md)
- [0002: Bun as runtime and toolchain](./0002-bun-runtime-toolchain.md)

When introducing a major architectural change:

1. Add a new numbered ADR file.
2. Describe context, decision, and consequences.
3. Link the ADR from this index.
