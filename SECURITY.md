# Security Policy

## Supported Versions

Security fixes are currently provided for the latest state of the `main` branch.

## Reporting a Vulnerability

- Do not open a public issue for security vulnerabilities.
- Use GitHub Security Advisories (Security tab -> Report a vulnerability) to submit a private report.
- Include reproduction steps, impact, and any suggested remediation if available.

We will acknowledge reports as quickly as possible, investigate, and coordinate
responsible disclosure for confirmed issues.
